Guia de implantação em Ubuntu Server LTS, arquitetura em containers Docker e manual de uso da nuvem privada projetada para o Grupo de Pesquisa em Engenharia Industrial (GPEI — Sala 201).

1. Visão Geral do Software

O OpenCloud é uma plataforma open-source de armazenamento em nuvem privada e colaboração em arquivos escrita em Go. Diferente de soluções tradicionais como o Nextcloud (que exigem PHP e banco de dados relacional MySQL/PostgreSQL), o OpenCloud utiliza uma arquitetura database-less baseada diretamente no sistema de arquivos (DecomposedFS).

No projeto do laboratório da Sala 201, ele foi escolhido para permitir que professores, pesquisadores e alunos compartilhem dados de pesquisa em pastas isoladas (Spaces) e editem planilhas e relatórios simultaneamente pelo navegador, sem depender de licenças pagas.

2. Arquitetura dos Serviços (Docker Compose)

A infraestrutura como código (pasta /iac) sobe 5 serviços interligados em uma rede bridge isolada (opencloud-net), onde apenas o proxy reverso fica exposto no servidor:

Container Imagem Oficial Porta Interna Função no Ambiente
gpei-traefik traefik:v3.7.16 80 / 443 (Host) Proxy reverso de borda e emissão automática de certificados TLS (Let's Encrypt).
gpei-opencloud opencloudeu/opencloud-rolling:9.0.0 9200/tcp Núcleo do sistema, provedor de login (IDP), Spaces e conector WOPI embutido.
gpei-collabora collabora/code:26.04.5.2.1 9980/tcp Edição colaborativa de documentos Office (.xlsx, .docx, .pptx) no navegador.
gpei-yjs opencloudeu/yjs:1.1.1 1234/tcp Servidor WebSocket para sincronização simultânea em tempo real (rota /yjs).
gpei-radicale tomsquest/docker-radicale:latest 5232/tcp Servidor CalDAV/CardDAV para agenda de bancadas e reuniões (rota /caldav/).

3. Requisitos de Sistema (Ubuntu Server)

  • Sistema Operacional: Ubuntu Server 22.04 LTS ou 24.04 LTS (64-bit).
  • Espaço em Disco (Armazenamento): Mínimo de 20 GB livres para testes (~3 GB do SO + 4 GB de Swap criado pelo script + ~3,5 GB das imagens Docker + espaço para dados). No servidor físico 1U da Sala 201, utilizam-se 2 TB úteis em RAID 1 (2x SSD NVMe).
  • Memória RAM e CPU: Mínimo de 2 vCPUs e 2 GB de RAM (com Swap de 4 GB ativo); recomendado 4 GB de RAM.
  • Portas de Rede: Portas 22/TCP (SSH), 80/TCP (HTTP) e 443/TCP (HTTPS) liberadas.
